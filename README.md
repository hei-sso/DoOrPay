## 📘 개요
Do Or Pay는 사용자가 습관 목표를 설정하고 포인트를 걸어 인증하는 모바일 애플리케이션입니다.\
목표 성공 시 포인트를 반환하고, 실패 시 포인트가 차감되며, 그룹 챌린지에서는 실패자의 포인트가 성공자에게 분배됩니다.

## 🧩 주요 기능
- 목표 생성/진행 관리 (개인/그룹)
- 포인트 충전/사용/잠금/반환/분배
- 사진 업로드 인증
- AI 이미지 분석 (중복/인터넷 이미지 검증)
- 인증 상태 관리 (PENDING → PROCESSING → APPROVED/REJECTED)
- 사행성 방지를 위한 정책 적용
- 다국어 지원

## 📦 기술 스택
- **Frontend**: React Native+Expo, TypeScript
- **Backend/Server**: Firebase (Auth, Firestore, Storage, Cloud Functions)
- **AI/ML**: TensorFlow.js, pHash, Reverse Image Search API
- **DB**: Cloud Firestore
